## 💎 每個概念包含的 5 維度深度結構
每個考點皆以嚴謹的學術與工程格式撰寫，包含：
1. **概念分析與考查目的（analysis）**：解析核心概念在 iPAS 中的出題意圖與應用背景。
2. **底層運作架構（pipeline）**：文字流程圖或數學公式推導步驟。
3. **必考專有名詞字典（glossary）**：必備專有名詞、對比反思與陷阱辨析。
4. **具體調校與工程手法（techniques）**：實戰工程參數調校（如超參數建議、防爆顯存手法）。
5. **開創性論文與法規出處（paper & paper_url）**：直通原創權威文獻。
